# Documentation Search

> **Note**: This skill previously searched Replit's specific documentation. Locally, use the **WebSearch** and **WebFetch** tools to find documentation for any framework, tool, or service.

## How to Find Documentation Locally

Use WebSearch with specific queries:

- "Next.js 14 app router documentation"
- "FastAPI background tasks tutorial"
- "PostgreSQL JSONB operators"
- "Stripe webhooks Node.js example"

Then use WebFetch to read the full page from the search result URL.
