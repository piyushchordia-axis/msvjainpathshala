# Hello World Skill

This skill provides a warm, personalized greeting along with the current date.

## Steps

1. Ask for the user's name if you don't already know it from context.
2. Greet them by name with a friendly message.
3. Tell them today's date in a human-readable format (e.g., "Wednesday, May 28, 2026").
4. Keep it short — one or two sentences total.

## Example output

> Hello, Alex! Today is Wednesday, May 28, 2026. Hope you're having a great day!
